## About the citations

Two of the sources are private hardware builds this corpus was derived from:
**reference project A** (an ESP32-S3 e-paper handheld) and **reference project
B** (a Zigbee sensor in a printed enclosure). Neither is public, so those
citations cannot be followed — read them as "this came from a real build"
rather than "look it up".

There is an irony worth naming: a skill about corroboration cites two sources
you cannot check. That is exactly why the labels are explicit rather than
dressed up as documentation. Under this skill's own rules those citations are a
single `measurement`-kind source apiece — strong for what they cover, and
useless for corroborating each other.

Anything sourced from a manufacturer datasheet, a core variant header or general
engineering practice is cited as such and can be checked normally.
